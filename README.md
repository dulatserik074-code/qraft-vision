# Qraft Vision / Talking Camera

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fdulatserik074-code%2Fqraft-vision)

Экспериментальная говорящая камера для незрячих и слабовидящих пользователей. PWA сочетает быстрое локальное распознавание известных объектов и опциональное полное описание сцены мультимодальной Vision AI.

> Приложение является вспомогательной экспериментальной технологией и не заменяет трость, собаку-проводника или профессиональные средства навигации.

## Возможности

- камера смартфона через HTTPS;
- локальный COCO-SSD (`lite_mobilenet_v2`) для быстрых событий даже без сети;
- полное описание сцены через защищённый backend provider chain;
- provider order: Gemini → OpenRouter → Hugging Face;
- ручная кнопка «Что передо мной?» и автоматическое описание каждые 2/3/5/10 секунд;
- уменьшение AI-кадра до 960 px, JPEG 76%, один запрос одновременно, timeout 14–15 секунд;
- подавление похожих описаний через нормализацию и Jaccard similarity;
- отдельный короткий cooldown опасности и приоритетное прерывание TTS;
- русский OCR через Tesseract.js;
- системный TTS с автоматическим выбором русского голоса;
- настройки локального/AI-анализа, подробности, голоса, речи, вибрации и debug;
- offline fallback: камера и загруженная локальная модель продолжают работать;
- installable PWA, ARIA/live regions, крупные touch targets и keyboard focus.

## Архитектура

```text
Camera → Local COCO-SSD → быстрые предупреждения
      └→ JPEG 960 px → /api/analyze → Gemini
                                    → OpenRouter fallback
                                    → Hugging Face fallback
                                    → similarity → TTS
```

Ключи никогда не попадают в frontend. `VisionProvider`, `RemoteVisionProvider`, `SceneDescriptionProvider` и будущий `DistanceProvider` разделены интерфейсами. Mock provider выключен и предназначен только для тестов.

## Бесплатный режим

Камера, локальная детекция, системный TTS и базовый OCR бесплатны. Полное AI-описание требует минимум один серверный ключ provider с доступной бесплатной квотой. Квоты и модели сторонних сервисов могут меняться; приложение честно продолжает локальный режим при их отсутствии.

### Environment variables

Добавьте минимум один provider в локальный `.env` или Render → Environment:

```env
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.5-flash

OPENROUTER_API_KEY=
OPENROUTER_MODEL=

HF_TOKEN=
HF_VISION_MODEL=
```

Для OpenRouter/Hugging Face имя модели задаётся явно, потому что доступность бесплатных vision-моделей меняется. Никогда не коммитьте `.env`.

## Локальный запуск

Требуется Node.js 20.19+.

```powershell
npm install
npm run build
npm run dev:server
```

Откройте `http://localhost:3000`. Для frontend hot reload запустите во втором терминале `npm run dev`; Vite проксирует `/api` на порт 3000.

```powershell
npm test
npm run typecheck
npm run build
```

## Render

`render.yaml` создаёт бесплатный Node web-service, который одновременно раздаёт PWA и обслуживает `/api/analyze`. После Blueprint deploy добавьте секрет `GEMINI_API_KEY` в Render Dashboard → qraft-vision → Environment и выполните redeploy. Без ключа сайт работает, но полное AI-описание сообщает о недоступности provider и сохраняет локальную детекцию.

## Проверка на Android

1. Откройте HTTPS-ссылку Render в Chrome/Edge.
2. Разрешите камеру и нажмите «Запустить камеру».
3. Проверьте автоматическое описание комнаты и ручную кнопку «Что передо мной?».
4. Отключите сеть: локальная детекция должна продолжиться, уведомление об offline — прозвучать один раз.
5. Проверьте «Прочитать текст», «Повторить», «Остановить» и порядок фокуса TalkBack.
6. Для установки выберите меню браузера → «Добавить на главный экран».

## Приватность и безопасность

Видео не записывается. Локальные кадры остаются в браузере. При включённом AI отдельные уменьшенные JPEG-кадры передаются выбранному внешнему provider через backend и не сохраняются приложением. Endpoint ограничивает размер 2.5 MB, частоту запросов и время выполнения. Перед использованием стороннего provider ознакомьтесь с его privacy policy.

## Ограничения

- COCO-SSD имеет фиксированный список классов; широкое понимание сцены работает только при настроенном Vision AI и интернете.
- Vision AI может ошибаться и галлюцинировать; опасность озвучивается только при явной формулировке модели, но не гарантируется.
- Реальное расстояние по monocular-камере не измеряется, метры не выдумываются. Для будущего ARCore/LiDAR предусмотрен `DistanceProvider`.
- OCR/детекция зависят от света, размытия и устройства. Первый запуск локальных моделей требует загрузки.
- Голосовое управление не включено: browser Speech Recognition не гарантирует offline.
- Нужны реальные испытания с незрячими пользователями и TalkBack до продуктовых заявлений.
