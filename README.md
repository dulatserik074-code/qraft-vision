# Qraft Vision / Talking Camera

Доступный экспериментальный web/PWA-MVP «говорящей камеры» для незрячих и слабовидящих людей. Камера распознаёт распространённые объекты, сообщает направление и примерную близость, читает русский текст и составляет короткое описание сцены.

> Приложение является вспомогательной экспериментальной технологией и не заменяет трость, собаку-проводника или профессиональные средства навигации.

## Что действительно работает

- задняя камера через `getUserMedia` с корректной остановкой потока;
- локальный COCO-SSD / TensorFlow.js (`lite_mobilenet_v2`);
- русские фразы, направление и грубая оценка близости;
- configurable cooldown, приоритеты, прерывание TTS и вибрация;
- ручное локальное описание сцены и русский OCR через Tesseract.js;
- системный TTS, настройки частоты 0.5–3 FPS и чувствительности;
- экспериментальное предупреждение о крупном известном объекте по центру;
- installable PWA, контрастный интерфейс, крупные цели и live regions.

## Установка и запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

На телефоне используйте HTTPS (исключение — localhost). Production находится в `dist/`. Для GitHub Pages публикуйте `dist` (`base: './'` настроен). Для Render: Static Site, build `npm install && npm run build`, publish directory `dist`.

## Offline-first и приватность

Кадры остаются в памяти, не сохраняются и не отправляются на сервер. TTS системный. После первой загрузки приложение и JS-модель кэшируются service worker. Языковые данные OCR требуют первой сетевой загрузки; повторный offline-доступ зависит от браузерного кэша. Базовая работа не требует API-ключа. `.env` исключён из Git.

## Android

Это web/PWA-демо, не native APK. На Android откройте HTTPS-версию в Chrome, разрешите камеру и выберите «Установить приложение». Native development build (React Native/Expo или Kotlin) нужен для гарантированного offline ML Kit/TFLite, нативного OCR и полного lifecycle. Обычный Expo Go для native ML-модулей недостаточен.

## Архитектура

Модули `camera`, `providers`, `ocr`, `speech`, `haptics`, `settings`, `utils` разделены. `VisionProvider` и `SceneDescriptionProvider` не связывают UI с конкретной моделью. Будущий облачный provider должен обращаться только к защищённому proxy; платный ключ нельзя помещать во frontend.

## Известные ограничения

- COCO-SSD не распознаёт дверь, лестницу/ступеньку, переход и произвольное препятствие — приложение не имитирует их.
- «Препятствие» — лишь крупный распознанный объект центрально в кадре; неизвестные препятствия могут быть пропущены.
- Реальная глубина не измеряется. Bounding box — неточная эвристика, метры не называются.
- OCR/детекция зависят от света, размытия и устройства. Web TTS/offline зависят от ОС и браузера.
- Голосовое управление не включено: browser Speech Recognition не гарантирует offline.
- iOS требует отдельной проверки VoiceOver/Safari/PWA.

## QA и тесты

Автотесты покрывают направление, близость, приоритет, фразы, cooldown и fallback. Перед релизом вручную проверить отказ/отсутствие камеры, background/foreground, TalkBack, выключенную речь/вибрацию, offline после первого запуска, нагрев и задержку на слабом Android. Испытания с незрячими пользователями обязательны.
